## Synchronize your `development` branch with the upstream repository.

Before starting new work you should always synchronize your copies of the `development` branch with the upstream [FarmData2 repository](https://github.com/FarmData2/FarmData2). By doing so you can be sure that your work is built on the most up to date version of FarmData2.

One way to synchronize your copies of the `development` branch is to run the following commands in a terminal in the FarmData2 development environment.

```bash
git switch development
git pull upstream development
git push origin development
```

Note: commands require that the current working directory is within the `/home/fd2dev/FarmData2` directory that contains the FarmData2 repository. You can use the following command at any time to make `/home/fd2dev/FarmData2` the working directory.

```bash
cd ~/FarmData2
```
