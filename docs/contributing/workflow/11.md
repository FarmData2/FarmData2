## 11. Request a Copilot Pull Request Review (optional).

<!-- eslint enable no-heading-punctuation -->
<!-- vale RedHat.HeadingPunctuation = YES -->
<!-- vale Google.HeadingPunctuation = YES -->
<!-- vale Microsoft.HeadingPunctuation = YES -->

If you have access to GitHub Copilot Pro consider requesting a [GitHub Copilot code review](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/request-a-code-review/use-code-review). By requesting a Copilot code review will receive feedback on your pull request and have the opportunity to improve it before a human FarmData2 maintainer reviews it. This will make it easier and faster for the human maintainer to review your pull request and provide feedback.

A [Copilot Pro plan](https://github.com/features/copilot/plans) (or greater) is required to access Copilot code reviews. [Teachers](https://docs.github.com/en/copilot/how-tos/copilot-on-github/set-up-copilot/enable-copilot/set-up-for-teachers-and-os-maintainers) and [Students](https://docs.github.com/en/copilot/how-tos/copilot-on-github/set-up-copilot/enable-copilot/set-up-for-students) are eligible to receive the [Copilot Pro Plan](https://github.com/features/copilot/plans) at no cost.

<!-- vale RedHat.SentenceLength = NO -->

If you find you are exceeding the included allotments of the Copilot Pro plan or the [usage limits for GitHub Copilot](https://docs.github.com/en/copilot/concepts/usage-limits) you can [add payment information](https://docs.github.com/en/billing/how-tos/set-up-payment/manage-payment-info) and [setup budgets](https://docs.github.com/en/billing/how-tos/set-up-budgets) to place monthly limits on costs. Detailed information about Copilot costs can be found on the [About GitHub Copilot code Review](https://docs.github.com/en/copilot/concepts/agents/code-review) page and in the [Models and pricing for GitHub Copilot](https://docs.github.com/en/copilot/reference/copilot-billing/models-and-pricing) document.
