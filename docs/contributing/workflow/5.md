## 5. Create and switch to a feature branch.

<!-- eslint enable no-heading-punctuation -->
<!-- vale RedHat.HeadingPunctuation = YES -->
<!-- vale Google.HeadingPunctuation = YES -->
<!-- vale Microsoft.HeadingPunctuation = YES -->

To contribute to the FarmData2 project you will commit your work to a feature branch created from `development`. You will later open a pull request asking that the changes in your feature branch be merged into the upstream `development` branch.

One way to create and switch to a new feature branch is to run the following commands in a terminal in the FarmData2 development environment. Be sure to use a short but meaningful name in place of `<feature_branch_name>`.

```bash
git switch development
git branch <feature_branch_name>
git switch <feature_branch_name>
```

The following command can be used to confirm that you have created and switched to your new feature branch.

```bash
git status
```
