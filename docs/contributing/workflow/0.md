## Prerequisite Knowledge.

The detailed instructions for each step of the FarmData2 workflow assumes some prerequisites. Each of the following topics links to a short tutorial that will get you started if you new to the knowledge and skill, or just want a refresher.

- **Files, Directories, and Paths**
  - [Filepaths Explained Simply | No Code Explanation](https://www.youtube.com/watch?v=e-4Qsg5e02E) by Madav Malhotra covers the key concepts well.
- **The Linux Command Line Interface (CLI) and the Bash Shell**
  - The "Basic Commands" section of the [Bash Tutorial](https://www.w3schools.com/bash/index.php) from W3Schools gives some hands-on practice with the necessary commands (and a few others).
- **Basic Git and GitHub Use**
  - The [An Intro to Git and GitHub for Beginners](https://product.hubspot.com/blog/git-and-github-tutorial-for-beginners) from HubSpot is a hands-on tutorial that covers the necessary fundamentals.

The [FarmData2 Quick Reference](../quickReference.md) includes tables summarizing the [Linux CLI Commands](../quickReference.md#linux-cli-commands) and [Git commands](../quickReference.md#git-commands) that are most commonly used in working on FarmData2.
