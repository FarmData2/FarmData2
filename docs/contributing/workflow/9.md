## 9. Push your feature branch to your fork on GitHub.

Pushing the feature branch containing your proposed changes makes a copy of the branch available on GitHub. Making your feature branch available on GitHub is a necessary step toward requesting that the maintainers consider merging your proposed changes into FarmData2.

One way to push your feature branch to GitHub is to run the following commands in a terminal in the FarmData2 development environment. Be sure to use the name of your feature branch in place of `<feature_branch_name>`.

```bash
git switch <feature_branch_name>
git push origin <feature_branch_name>
```
