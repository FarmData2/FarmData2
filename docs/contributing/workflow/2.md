## 2. Comment on the issue ticket that you found.

Commenting on the ticket lets the FarmData2 community know that you are interested in working on it. Asking questions or initiating a discussion can also save you time and lead to a better solution.

- Minimally you might comment "I want to work on this issue."
- If the issue is not clear enough, try asking a clarifying question.
- If you are not sure how to get started, consider asking for some pointers.
- If you have an idea of how to address the issue, describe how the approach you plan to use.
- If there is more than one way to address the issue, start a conversation about the alternatives.

Do not submit pull requests for tickets that have been assigned to someone else. If work on an assigned ticket seems to have been dormant for a few weeks or longer, comment on the ticket [mentioning (_tagging_)](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax#mentioning-people-and-teams)] the assignee and ask asking if they are continuing to work on it.

If you decide not to continue working on an issue, make another comment on its ticket so that it can be unassigned and that others can consider working on that issue.
