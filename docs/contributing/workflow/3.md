## 3. Create or Restart the FarmData2 development environment codespace.

<!-- eslint enable no-heading-punctuation -->
<!-- vale RedHat.HeadingPunctuation = YES -->
<!-- vale Google.HeadingPunctuation = YES -->
<!-- vale Microsoft.HeadingPunctuation = YES -->

The FarmData2 development environment provides the tools and servers necessary for working on FarmData2 in a GitHub codespace. The only dependency that is required on your machine is a [Browser based on Chromium](<https://en.wikipedia.org/wiki/Chromium_(web_browser)#Browsers_based_on_Chromium>). The development environment includes a Visual Studio Code IDE, a live instance of [farmOS](https://farmos.org/) with FarmData2 installed, a desktop environment for running tests in the Cypress GUI, and a documentation server.

See the following sections of the [INSTALL.md](../../../INSTALL.md) file for more information.

- [Creating a FarmData2 Codespace](../../../INSTALL.md#creating-a-farmdata2-codespace)
- [Stopping / Restarting / Deleting your FarmData2 Codespace](../../../INSTALL.md#stopping--restarting--deleting-your-farmdata2-codespace)
